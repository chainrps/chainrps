忘记密码？

在服务器执行以下命令重置为默认密码 ADMIN：

# 方式一：一键重置脚本（推荐）
.venv\Scripts\python.exe scripts\reset_admin_password.py

# 方式二：直接 SQL
sqlite3 data\rps.db "UPDATE admins SET password_hash='' WHERE username='admin';"
# 然后重启后端，会自动用默认密码 ADMIN 重新初始化
